# Cardputer ADV Pet

Питомец ходит по экрану, реагирует на звуки (хлопок, громкий шум, музыка) и на клавиши.

Клавиши: F — покормить, P — поиграть, S — спать/разбудить, любая другая — разбудить.
Звуки: хлопок — радуется и прыгает, очень громко — пугается и убегает, долгая музыка/шум — танцует.
Состояние (еда/радость/энергия) сохраняется в памяти.

## Сборка
    pip install platformio
    pio run
Готовый файл: `.pio/build/cardputer/firmware.bin` — это app-only bin, его и нужно класть на SD в /Launcher
(НЕ используй merged/bootloader-образ, Launcher его не примет).

Или залей папку в GitHub-репозиторий: Actions → Build firmware → скачай артефакт `cardputer-pet-bin`.
